#  Weather

Учебный проект для практики DevOps-навыков: контейнеризация, оркестрация, CI/CD и работа с БД. Приложение для просмотра текущей погоды в любом городе мира с сохранением истории запросов в PostgreSQL.


---

##  О проекте

Weather — это full-stack приложение, которое:

- Ищет город через публичное API [wttr.in](https://wttr.in/) (без API-ключей)
- Показывает текущую температуру, влажность, скорость ветра и описание погоды
- Сохраняет историю запросов в PostgreSQL
- Отображает последние 20 запросов с временем и температурой
- Полностью работает в Docker (3 контейнера: фронтенд, бэкенд, БД)
- Автоматически собирается и тестируется через GitHub Actions
